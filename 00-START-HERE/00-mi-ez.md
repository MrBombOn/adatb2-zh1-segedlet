# Mi ez a segédlet?

Saját **Oracle / SQL ZH1** tanulási és szintaktikai segédlet magyarul.

## Mit kapsz?

- Fogalmak egyszerű + technikai magyarázattal
- SQL fejezetek felismerés–szintaxis–hiba–ellenőrzés struktúrában
- Placeholder sablonok (`<tabla>`, `<feltetel>`)
- Gyakorló feladatok kitalált sémán (STUDENT/COURSE vagy AUTHOR/BOOK)

## Mit NEM kapsz?

- Konkrét ZH-megoldást
- Kurzus PDF / Moodle anyagot
- „Másold be és kész” választ

## Hogyan épül fel egy fogalomlap?

1. Egyszerű definíció  
2. Óvodás magyarázat  
3. Technikai magyarázat  
4. Mini példa (tanulási)  
5. Tipikus félreértés  
6. ZH-felismerés
