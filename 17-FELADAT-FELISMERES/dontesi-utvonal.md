# Döntési útvonal (ZH perc alatt)

1. **Olvas vagy ír?** → SELECT vs DML/DDL  
2. **Hány tábla?** → 1 vagy JOIN  
3. **Szűrés sorokra?** → WHERE  
4. **Csoport / statisztika?** → GROUP BY + aggregátum  
5. **Szűrés a csoportra?** → HAVING  
6. **Rendezés?** → ORDER BY  
7. **NULL a sztori része?** → IS NULL / NVL  
8. **Dátum formátum?** → TO_DATE / TO_CHAR  

Ha elakadsz: rajzold le a táblákat és a PK–FK nyilakat.
