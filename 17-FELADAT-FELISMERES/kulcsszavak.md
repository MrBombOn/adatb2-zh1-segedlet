# Kulcsszavak → SQL eszköz

| Szövegminta | Tipikus eszköz |
|-------------|----------------|
| listázd, mutasd, add vissza | SELECT |
| csak azok, ahol, feltéve hogy | WHERE |
| csökkenő / ABC | ORDER BY |
| különböző / egyedi értékek | DISTINCT vagy UNIQUE |
| együtt / tartozik / neve és … | JOIN |
| akkor is, ha nincs | LEFT JOIN |
| X-enként / csoportonként | GROUP BY |
| legalább N darab csoportban | HAVING |
| hány / összeg / átlag | COUNT/SUM/AVG |
| vedd fel / új sor | INSERT |
| módosítsd | UPDATE |
| töröld a sorokat | DELETE |
| hozz létre táblát | CREATE TABLE |
| elsődleges kulcs | PRIMARY KEY |
| hivatkozzon | FOREIGN KEY |
| véglegesítsd / vonjad vissza | COMMIT / ROLLBACK |
| ha nincs legyen 0 | NVL |
| hiányzik / nincs kitöltve | IS NULL |
