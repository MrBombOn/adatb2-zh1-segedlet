# Környezet – áttekintés

Oracle tanuláshoz három gyakori út:

1. **Windows natív** – Oracle XE / Free + SQL Developer vagy SQLcl  
2. **Docker** – konténerben futó Oracle adatbázis  
3. **WSL2** – Linux környezet Windowson, gyakran Dockerrel együtt  

Cél: tudj **csatlakozni**, futtatni egy `SELECT * FROM dual;`-t, és legyen saját gyakorló sémád.

Következő: válassz egy utat (`01`–`03`), majd `04`–`07`.
