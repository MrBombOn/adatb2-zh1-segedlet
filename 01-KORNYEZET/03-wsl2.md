# WSL2 útvonal

1. WSL2 + distro (pl. Ubuntu) telepítése Windowson  
2. Docker engine a WSL2-ben **vagy** Docker Desktop WSL integration  
3. Oracle konténer futtatása a WSL/Docker úton  
4. Kliens: Windows SQL Developer → `localhost` port map, vagy linuxos SQLcl a WSL-ben  

## Mikor válaszd?

- Szereted a linuxos CLI-t
- Már van WSL munkafolyamatod
- Intézményi lab is WSL/Docker alapú

## Tipikus hiba

Port ütközés Windows szolgáltatásokkal; firewall; WSL IP vs `localhost` keverése.
