# Tábla létrehozás

**P0** · SEQUENCE nem IDENTITY

```sql
CREATE TABLE <tabla> (
  <id>    NUMBER NOT NULL,
  <nev>   VARCHAR2(<n>) NOT NULL,
  <datum> DATE,
  CONSTRAINT <pk> PRIMARY KEY (<id>)
);
CREATE SEQUENCE <seq> START WITH 1 INCREMENT BY 1;
```

Adattípus: szám→NUMBER, szöveg→VARCHAR2(n), dátum→DATE.
