# ZH stratégia

## Időbeosztás (példa 60 percre)

| Perc | Teendő |
|------|--------|
| 0–5 | Egész feladatsor átolvasása, könnyűek megjelölése |
| 5–25 | SELECT / WHERE / egyszerű JOIN |
| 25–40 | GROUP BY / LEFT JOIN / dátum |
| 40–50 | DML/DDL/constraint |
| 50–60 | Ellenőrzés, szintaxis, NULL |

## Minden feladatnál 4 kérdés

1. Mit kérnek kimenetként?  
2. Mely táblák és kulcsok?  
3. Szűrés / csoport / rendezés?  
4. Hány sort várok?

## Ha elakadsz

- Egyszerűsíts: előbb `SELECT * FROM t WHERE …`  
- Rajzolj PK–FK nyilakat  
- Cseréld LEFT/INNER-t fejben  
- Nézd `17-FELADAT-FELISMERES/` kulcsszavait
