# Instance és database

## Egyszerűen
Az **instance** az „élő motor” (RAM + processzek).  
A **database** a lemezen lévő adat.

## Óvodás
A könyvtáros (instance) dolgozik; a könyvek a polcon (database).

## ZH-felismerés
„Leállt az instance” ≠ feltétlenül elvesztek a COMMIT-ált adatok (durability), de a kapcsolat megszakad.
