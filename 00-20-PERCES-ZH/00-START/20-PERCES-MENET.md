# 20 perces menet

1. **0–1 perc:** egész feladatsor elolvasása  
2. **1–3 perc:** jelöld a típusokat + függőségi sorrend  
3. **3–8 perc:** DDL (user/tábla/constraint)  
4. **8–12 perc:** DML (INSERT/MERGE/szétválogatás)  
5. **12–18 perc:** SELECT / JOIN / GROUP / Top-N  
6. **18–20 perc:** ORA javítás + végső ellenőrzés  

```text
USER → TABLE szulo → TABLE gyerek → SEQUENCE → INSERT szulo → INSERT gyerek → VIEW → SELECT → COMMIT?
```
