## Magyar szinonimák (feladatszöveg)
- listáz / mutass / írd ki → SELECT
- hozz létre / definiálj → DDL
- vegyél fel / illeszd → INSERT
- módosíts / állíts → UPDATE
- törölj (sorokat) → DELETE
- kapcsolj / együtt → JOIN
- csoportonként → GROUP BY
- leg… / első / top → ROWNUM
